# Roadmap

Этапы от первой живой мобильной версии к полной автономной системе на облачном сервере. Порядок может корректироваться по ходу использования; правила продукта описаны в [`product.md`](product.md).

1. **Этап 1. Мобильное приложение (iPhone PWA) + календарь по дням недели + авточтение почты `Lesteatres@mail.ru` и Telegram-приёмник** *(текущий этап)*
   - Полноценный мобильный интерфейс для iPhone с ползунковым переключателем **«Кто: `А` ↔ `+1`»**, раздельным обучением вкуса на свайпах, 3-й вкладкой **«Нравятся»** (с автопоиском режиссёров/хореографов по всем театрам Москвы) и раскладкой **по неделям и дням недели (Пн–Вс)** с двухмесячным drag-календарём отъездов и ручным вводом времени/мероприятия по нажатию на дату.
   - Регулярное авточтение билетной почты **`Lesteatres@mail.ru`** по IMAP + хранилище купленных билетов (PDF-бланки, QR-коды, ряд/места, кто идёт) и общий **Telegram-бот** — купленные билеты автоматически отмечаются в недельном расписании как «Уже есть».
   - Умный разбор входящих в Telegram-боте и из «Фото»: бот сам отличает уже купленный билет от скриншота/поста «хочу сходить».
   - Эталонный каталог и живой сканер: Туминас, Крымов, Бутусов, Театр «Озеро», Большой театр, МАМТ и Театр «Около дома Станиславского» + кросс-театральный поиск любимых постановщиков по Москве.

2. **Этап 2. Подключение полного списка театров, музеев и инфлюенсеров (Telegram + Instagram)**
   - Загрузка пользовательского списка московских театров, выставочных пространств и каналов инфлюенсеров.
   - Ежедневный парсинг Telegram-каналов и Instagram-аккаунтов с выделением двух типов сигналов: 1) рекомендации новых спектаклей и выставок, 2) точные анонсы даты и часа старта продаж билетов.

3. **Этап 3. Браузерный автопокупатель и «снайпер» открытия продаж (Playwright + 3D-Secure мост)**
   - Автоматический проход по официальным билетным виджетам театров (Ticketland/Radario/собственные шлюзы Вахтангова, МХТ, Театра Наций, РАМТа): выбор 1–2 соседних мест по карте проходов, автозаполнение именных билетов выбранных зрителей.
   - Зашифрованное хранилище карты, автозаполнение платёжной формы до пуша в банк-клиент и живой мост для одноразового кода 3D-Secure прямо в мобильном приложении + Web Push уведомления на iPhone.
   - Точный минутный будильник («снайпер») под время открытия продаж дефицитных спектаклей.

4. **Этап 4. Перенос на круглосуточный облачный сервер (HTTPS + автономность 24/7)**
   - Развёртывание на VPS с постоянным HTTPS-доменом и паролем/биометрией входа, чтобы телефон и сервер работали полностью независимо от домашнего компьютера 24/7.
