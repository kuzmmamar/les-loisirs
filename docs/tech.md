# Технологический стек и архитектура

## Решение

Бэкенд и сканер на Python 3.12 (`uv`), мобильный клиент — лёгкое и быстрое iOS-ориентированное PWA (Progressive Web App), отдаваемое тем же сервером без отдельной Node-сборки. Никаких десктопных экранов нет.

| Компонент | Выбор и причина |
| --- | --- |
| Язык и окружение | Python 3.12+ через `uv` (`pyproject.toml`, `uv.lock`) — мгновенная установка и воспроизводимость |
| Сервер и API | `FastAPI` + `uvicorn` — быстрый JSON API, отдача PWA-манифеста, сервис-воркера и приём скриншотов с iPhone |
| База данных | `SQLite` (`data/parter.db`, режим WAL) — надёжное транзакционное хранение репертуара, показов, статусов «Был / Не хочу / Охота», профилей «Кто идёт», скриншотов и очереди покупок |
| Сканер афиш | `httpx` + `beautifulsoup4` — прямой опрос официальных сайтов театров с проверкой по белому списку доменов |
| Планировщик | Встроенный фоновый планировщик (`asyncio`) — ежедневный скан расписаний, проверка папки скриншотов каждые 60 секунд и минутные таймеры стартов продаж |
| Чтение скриншотов и ИИ | `openai` (OpenAI-совместимый мультимодальный API при наличии ключа в `.env`) + локальный OCR на базе системного `Vision.framework` macOS / эвристического парсера текста на случай отсутствия ключа |
| Автопокупка (этап 3) | `Playwright` (Chromium) + шифрование реквизитов `cryptography` (Fernet / системный ключ в `.env`, вне git) |
| Мобильный интерфейс | Чистый адаптивный мобильный веб-клиент (HTML5 + CSS Variables + Vanilla JS, PWA `manifest.webmanifest` + `sw.js`, iOS Safe Area, тактильная навигация снизу) |
| Чтение альбома «Фото» на iPhone | 1) Готовый эндпоинт `/api/inbox/shortcut` для автоматизации iOS «Быстрые команды» (триггер на альбом «Театр» в Apple Фото); 2) выбор из альбома прямо в приложении; 3) фоновый мониторинг локальной папки `data/photos_inbox/` (можно указать на синхронизируемую папку iCloud) |

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `parter/main.py` | Точка входа FastAPI, маршруты API, PWA и фоновые задачи |
| `parter/db.py` | Схема SQLite, миграции и запросы |
| `parter/catalog.py` | Эталонный справочник постановок (Туминас, Крымов, Бутусов), белый список официальных касс и геометрия залов (1-й ряд, 5-й ряд, ряды за проходом) |
| `parter/scraper.py` | Живой сканер официальных сайтов театров (`vakhtangov.ru`, `mxat.ru`, `theatreofnations.ru`, `ramt.ru`, `teatrpushkin.ru`, `satirikon.ru`, `sdart.ru`) и детектор изменений |
| `parter/planner.py` | Логика ранжирования мест, фильтрации «Был / Не хочу» и сборки недельных предложений |
| `parter/screenshots.py` | Умный разбор входящих файлов (PDF билетов, скриншоты QR и афиш): отличает купленный билет от хотелки, извлекает дату/время/ряд/место |
| `parter/mail_inbox.py` | Регулярное фоновое чтение почты `Lesteatres@mail.ru` по IMAP SSL (`imap.mail.ru:993`): разбирает письма касс и PDF-вложения, защищает от дублей и автоматически отмечает купленные билеты в «Расписании» |
| `parter/tg_bot.py` | Telegram-бот (Long Polling через `httpx`): принимает PDF билетов, скриншоты и пересланные посты и складывает их в базу |
| `parter/checkout.py` | Конвейер оформления заказа и статуса ожидания 3D-Secure / банковского пуша |
| `parter/static/` | Мобильное PWA-приложение (`index.html`, `styles.css`, `app.js`, `manifest.webmanifest`, `sw.js`, иконки) |
| `data/` | База `parter.db`, загруженные скриншоты и `photos_inbox/` (не в git) |
| `scripts/app.sh` | Управление запуском (`start`, `stop`, `restart`, `status`) |

## Запуск и проверка

Управляет сервисом только агент через `scripts/app.sh`:
- `scripts/app.sh start` — синхронизирует окружение (`uv sync`) и поднимает ровно одну фоновую копию на `0.0.0.0:8520` (доступна и локально, и с iPhone в той же Wi-Fi сети по локальному IP компьютера до переноса на облачный VPS).
- `scripts/app.sh status` — показывает статус и ссылки (включая локальный адрес для iPhone).
- `scripts/app.sh restart` / `scripts/app.sh stop` — перезапуск и остановка.
