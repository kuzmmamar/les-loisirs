# Les Loisirs — мобильный театральный и выставочный консьерж

Полностью мобильное приложение (iOS PWA с иконкой на экране «Домой») и фоновый агент для Москвы:

- ежедневно сканирует официальные кассы театров, выставок и соцсети инфлюенсеров (без перекупщиков и сайтов-двойников);
- ведёт личный каталог предпочтений (**«Уже был»**, **«Не хочу»**, **«Охота»**) и распознаёт скриншоты из альбома «Фото» на iPhone;
- составляет понятные недельные предложения с выбором **«Кто идёт»** (1–2 билета) и проверкой конкретных мест: **середина, 1-й ряд, 5-й ряд или ряд сразу за поперечным проходом** (где больше места для ног);
- отслеживает минуты открытия продаж и сам оформляет билеты по карте до пуша / 3D-Secure подтверждения в мобильном банке.

Стартовый фокус (Этап 1): спектакли и спецпоказы **Римаса Туминаса**, **Дмитрия Крымова** и **Юрия Бутусова** в Москве.

Телефон открывает рабочее приложение с включённого компьютера. Эта страница GitHub хранит проект и сама по себе на экран «Домой» приложение не ставит.
